# Blue Vinyl

## Run Locally

Requires Node.js.

```sh
npm run dev
```

`npm run watch` does the same thing. Serves the app at http://localhost:3000 and opens it in the browser. The page updates on its own when `index.html`, `src/` or `data/` changes: CSS is swapped in place, everything else reloads the page.

To serve the app without live reload:

```sh
npm start
```
