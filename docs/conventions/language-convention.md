# Language Convention

English is the default language for everything in this repository.

This applies to:

- Source code, including identifiers, comments, and log messages
- Documentation (`docs/`, README, and similar files)
- Commit messages (see [commit-convention.md](commit-convention.md))
- Issue templates, issues, pull requests, and review comments
- Configuration files and scripts

Use another language only when a specific case requires it, for example user-facing localized strings.
